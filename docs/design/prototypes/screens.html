Seven screens, seven decisions

Start screen

Large tiles instead of lists, a fixed colour per topic, subtitles naming the type and the size. Someone opening the app for the first time should know what is behind a tile without being told.

Every tile in this prototype carries a token class — t-sand, t-salbei — and the mode block resolves it. No colour value appears in the markup, exactly as no colour value will appear in the database.

  • Caregiver view: read and act, nothing else. No plus button, no handles, nothing that can break.
  • Parent view: unlocked by PIN, revealing the pencils and the add tile.
Guide

The core format. A step fills the screen: picture, one sentence in large type, an optional hint and a recording. Swipe or tap to move on.

The moon button in the app bar switches straight to night mode. This is the reason the third appearance mode exists — reading aloud in a darkened bedroom, where a white screen is a product defect. Try it.

Checklist

Every tick writes a timestamp. In the evening the parents can see what happened when, without anyone having to document anything.

It stays a plain event list on purpose: no evaluation, no trends, no scoring. That restraint is what keeps the app outside medical device territory.

Note the progress bar: it is amber, the reserved system colour. That is why amber is not offered as a tile colour — once users could paint tiles amber, the signal would stop reading as the app speaking.

Table

The app imposes no structure. Someone who wants a "Time" column creates one; someone who needs "Place" instead does that. The same tile carries a daily schedule, a contact list or a packing list.

Technically this is a JSON payload of column names and rows, which means later tile types need no database migration.

Get help

The bar is pinned above every screen. Behind it are the stored numbers, large, labelled with a relation.

A tap opens the phone app with the number ready but does not dial. That needs no call permission, is harmless if triggered by mistake, and keeps the app out of emergency-services regulation.

The bar now uses #C0392B in light mode. The earlier draft used a lighter red on which white text reached only 3.95:1 — below the minimum, on the one element that has to be readable in a second under stress.

New tile

Creating a tile starts with the type, followed by a form tailored to it. That is considerably easier to grasp than a construction kit where elements combine freely.

New types can be added later without touching existing content. Older app versions skip unknown types on import rather than failing on them.

Backup & transfer

Export produces a single file — a ZIP holding a manifest, the content and the media. For the destination the app opens the Android system dialog, where every installed cloud service appears as a target.

So the app needs no Drive API, no OAuth approval, and no internet permission at all. The same file doubles as the handover package for a second caregiver, optionally password-protected.

Still open

Template picker on first run, search results, the inside of a folder, PIN entry, and the editing form per tile type. Those screens are worth drawing once the structure above is settled.
