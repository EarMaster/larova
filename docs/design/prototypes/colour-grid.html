Design system · Colour

Eight colours for the user, two for the app.

The app speaks in amber and red — progress, active step, get help. Everything a user colours themselves speaks in the eight tile tones. That split is why the palette stops at ten values instead of eighteen.

The two reserved colours

Neither is offered as a tile colour. They are the app’s voice, not the user’s.

Amber · the brand

Amber

The lamp in the icon. In the app it marks the active step, progress, and anything happening right now. #FFC46B on dark surfaces, #9E5E0C for text and symbols on light ones — the bright tone carries no text at 2.4:1.

Get help

Alarm

The help bar and nowhere else. #C0392B with white text in light mode, #FF9B8F on #2A1512 in dark mode. Because this colour appears exactly once in the product, it is never misread.

A defect found in the first prototype

The help bar used #D9544A there. White text reaches only 3.95:1 on it, below the minimum, on the one element that has to be readable in a second under stress. The corrected value #C0392B reaches 5.44:1 and is now applied in the screen prototype.

Every value

Contrast is measured against the title colour of each mode. The threshold for body text is 4.5:1.

What the logo contributes — and what it does not

Taken over: indigo and cream

The icon’s night blue is the dark mode surface, the cream is the light one. App and icon are literally made of the same material — on the home screen you see the app’s own background in miniature.

Not taken over: amber as a tile colour

Offering the brand colour as a ninth tile colour would have been the obvious move, and a mistake. Amber marks what is happening right now — the active step in a guide, the filled part of a progress bar. Once every third tile is amber, that signal stops working, permanently, because users assign the colours themselves.

The same rule applies to red, which is why the palette contains no saturated red. Clay and Rose sit either side of it and are deliberately muted, so nothing on a tile can look like an alarm.

The compromise is Sand. A desaturated relative of the brand amber: close enough for family resemblance, far enough not to be mistaken for the signal. That is why Sand comes first and is the default for new tiles.

Rules for implementation

Store the key, never the value. The database holds colorToken = "salbei". The theme resolves it into one of three surfaces depending on the mode. Storing the hex value instead makes every user tile unreadable in dark mode — retroactively, with no way to repair it.

Colour is never the only differentiator. Every tile also carries a symbol and a label. Under red-green colour blindness Moss and Clay converge visibly; the tile stays unambiguous because text and symbol do the work.

Night is not a third palette. It is the dark palette pulled 55 % toward #12101F with warm rather than cool ink. That can be expressed as a function instead of another table — eight fewer values that can drift.
